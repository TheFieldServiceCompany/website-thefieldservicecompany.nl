Filter de WordPress-mediabibliotheek op extensie, pixelafmetingen, bestandsgrootte, oriëntatie en alt-tekst.

== Description ==

Gebruik Extra filters in de raster- of lijstweergave van de mediabibliotheek.
Filters combineren met de bestaande mapselectie van HappyFiles.
Indexeer bestaande bestanden eerst via Media > Mediafilters.
Zie README.md voor gebruik, beperkingen en onderhoud.

== Installation ==

1. Upload het ZIP-bestand via Plugins > Nieuwe plugin > Plugin uploaden.
2. Activeer TFSC Mediafilters.
3. Start de index via Media > Mediafilters en wacht tot deze klaar is.
4. Selecteer een HappyFiles-map en gebruik Extra filters.
