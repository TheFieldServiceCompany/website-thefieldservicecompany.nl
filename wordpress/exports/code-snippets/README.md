# Code Snippets-exports

Deze map bevat ongewijzigde, gedateerde exports uit de WordPress Code
Snippets-plugin.

- Gebruik een datum als mapnaam: `YYYY-MM-DD`.
- Wijzig exportbestanden niet handmatig.
- Plaats beheerde, leesbare broncode onder `wordpress/snippets/`.
- Noteer in `wordpress/snippets/README.md` welke versie actief is en waarvan
  een export slechts een herstelkopie of historische variant is.

De map `2026-10-17/` bevat de geïnventariseerde live-export van 17 oktober
2026, inclusief de volledige actieve JSON-export, losse exports en toegepaste
herstelkopieën.
